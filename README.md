## Download

Download the latest version of Gemora Desktop from the **Releases** page.

### Windows

| Package | Recommended for |
| --- | --- |
| `Gemora-0.2.0-Setup-x64.exe` | Standard Windows installation |
| `Gemora-0.2.0-Portable-x64.exe` | Portable version — no installation required |

### Linux

| Package | Recommended for |
| --- | --- |
| `Gemora-0.2.0-amd64.deb` | Debian / Ubuntu-based distributions |
| `Gemora-0.2.0-x64.AppImage` | Portable build for compatible Linux distributions |

> Current desktop builds are available for **64-bit Windows and Linux**.

## Installation

### Windows — Setup

1. Download `Gemora-0.2.0-Setup-x64.exe`
2. Open the installer
3. Follow the installation steps
4. Launch Gemora

### Windows — Portable

1. Download `Gemora-0.2.0-Portable-x64.exe`
2. Place the file wherever you want
3. Run it directly

No installation is required.
